# Security

Please don't report security problems in public issues.

Report them privately on GitHub: open this repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/ykwimk/agent-overtime/security/advisories/new)). Only the maintainer sees the report.

Please include what you found, how to reproduce it, and the versions of the app, macOS and Claude Code. We'll reply as soon as we can. Once a fixed release is out, the advisory is published with credit to you, unless you'd rather not be named.

Fixes go into the latest release only.

For what the app reads, keeps and sends (only the update check goes over the network), see [How it works](README.md#how-it-works).
